# 📊 Data Analytics Internship — End-to-End E-Commerce Analysis

## 📌 Project Overview
This repository contains a comprehensive 4-week Data Analytics internship project focused on analyzing an e-commerce transactional dataset comprising **1,200 orders**. The project spans the entire data lifecycle: from raw data cleaning and exploratory analysis to advanced SQL querying and dashboard visualization.
