# Week 2: Exploratory Data Analysis (EDA)

## 📌 Project Overview

This week's task focuses on performing Exploratory Data Analysis (EDA) on an e-commerce order dataset of 1,200 records using Google Sheets and built-in Gemini AI capabilities.

## 🛠️ Tools \& Technologies

* **Google Sheets**
* **Gemini AI (Inbuilt)**
* **Excel / OpenXML Data Pipeline**

## 📊 Summary of Findings

### 1\. Key Descriptive Statistics

* **Total Records:** 1,200 orders
* **Average Order Value (TotalPrice):** $1,053.97 (Median: $823.62)
* **Average Unit Price:** $356.41
* **Average Quantity per Order:** \~3 items

### 2\. Product Category Performance

* **Highest Avg Total Price:** Laptops ($1,110.56)
* **Lowest Avg Total Price:** Phones ($972.58)
* **Top Overall Revenue Generators:** Chairs ($195.6k) and Printers ($195.6k)

### 3\. Outlier Analysis

* Identified 8 high-value order outliers exceeding **$3,300** in total order value.
* Peak order value recorded: **$3,456.40** (`ORD200789` - 5 Tablets).
* Outliers are driven by maximum item quantity (5) combined with high unit prices (> $670).
